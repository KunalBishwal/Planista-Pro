# 📅 Planista-Pro

Planista-Pro is a **full-stack Event Planning & Management System** designed to streamline the process of booking venues, managing events, handling staff, and processing payments — all in one platform.

## 🚀 Features
- **Venue Management** – Search & filter by location, price, and availability.
- **Event Booking** – Real-time booking system with secure payment options.
- **Staff Management** – Assign staff to events and track availability.
- **User Authentication** – Secure email/password login using NextAuth.js.
- **Analytics Dashboard** – Monitor events, bookings, and revenue.
- **Fully Responsive** – Optimized for desktop, tablet, and mobile.

## 🛠 Tech Stack
- **Frontend:** React, Tailwind CSS, Framer Motion
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Authentication:** NextAuth.js
- **Payments:** Stripe / PayPal
- **Real-Time Updates:** WebSockets / Polling
